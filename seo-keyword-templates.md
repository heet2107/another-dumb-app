## ✅ SEO Checklist for Keywords

1. **Primary Keyword Usage**
   - [ ] In URL slug
   - [ ] In H1 title
   - [ ] In first sentence
   - [ ] 5+ times in content
   - [ ] In 3+ H2/H3 headings
   - [ ] Bolded 2-3 times
   - [ ] In meta description
   - [ ] In conclusion

2. **Secondary Keywords**
   - [ ] Natural integration throughout
   - [ ] In subheadings where relevant
   - [ ] In image alt text
   - [ ] In bullet points
   - [ ] In examples

3. **Semantic Keywords**
   - [ ] Related terms included
   - [ ] Industry jargon explained
   - [ ] Synonyms used naturally
   - [ ] Context-specific variations

Remember: Keywords should always be integrated naturally. Focus on providing value to readers while optimizing for search engines and AI algorithms.
